2. Ce que propose le jeu gratuitement

Le jeu se télécharge gratuitement, sur iPhone et iPad avec iOS 17 ou plus récent, sans compte. On y joue en anglais, français ou espagnol. Sont gratuits :

  • le défi du jour complet, identique pour tous les joueurs d'une même langue ;
  • la série et son joker mensuel, qui ne s'achète jamais ;
  • les 7 derniers jours de l'archive ;
  • 3 Sprints par jour ;
  • l'Entraînement et son aide ;
  • les statistiques essentielles : série, meilleur score, nombre de défis ;
  • le partage d'une image ou d'une vidéo de votre grille, le widget, la notification du matin, les classements et succès Game Center si vous l'allumez (article 7) ;
  • les apparences Auto, Jour et Nuit, et toutes les fonctions d'accessibilité.

Le défi du jour, la série et les 7 derniers jours ne deviendront pas payants.

Le jeu contient 400 tirages quotidiens par langue, qui couvrent les jours jusqu'au 1er décembre 2027. Au-delà, tant qu'une mise à jour n'en a pas ajouté, les tirages reviennent dans le même ordre.

Le jeu est sans publicité de tiers : ni régie publicitaire, ni abonnement. À la fin d'une partie, il peut afficher une bannière discrète vers un autre jeu d'Aplomb, jamais à qui a acheté l'Édition complète (article 9).

6. Accessibilité

Le jeu se joue avec VoiceOver, suit la taille du texte d'iOS jusqu'à 310 %, l'option « Augmenter le contraste » et « Réduire les animations », et ne repose jamais sur la seule couleur pour signaler un état. Le widget garde une taille de texte fixe. Ces informations sont tenues à jour dans ce document ; sur demande à contact@aplomb-apps.fr, elles vous sont fournies dans un format accessible.

7. Services d'Apple : iCloud et Game Center

iCloud. Si vous êtes connecté à iCloud, le jeu copie votre historique dans votre compte pour le retrouver sur vos autres appareils et après une réinstallation. L'éditeur n'a pas accès à cette copie. Réglages › « Effacer mes données » l'efface (détail dans la politique de confidentialité).

Game Center. Un interrupteur dans les Réglages du jeu, éteint par défaut, commande Game Center. Ce réglage est propre à chaque appareil et n'est pas copié dans iCloud. Éteint, le jeu ne se connecte pas à Game Center, n'y envoie rien et ne met rien en attente. Si vous l'allumez, le jeu se connecte, envoie les succès déjà acquis d'après votre historique, puis vos scores suivants ; votre score et votre pseudo sont visibles des autres joueurs. Si vous l'éteignez, la file d'attente sur l'appareil est vidée ; ce qui est déjà chez Apple y reste. Sans Game Center, le jeu reste entier.

Ces services sont fournis par Apple sous ses propres conditions, sans garantie de disponibilité permanente de la part de l'éditeur. Les scores ne sont pas vérifiés par un serveur de l'éditeur ; les classements et succès n'ont aucune valeur marchande et ne donnent droit à aucun lot.
