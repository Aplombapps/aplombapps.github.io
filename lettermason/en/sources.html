1. Word lists

English — SCOWL 2020.12.07 (Spell Checker Oriented Word Lists), Kevin Atkinson, wordlist.aspell.net. The game uses levels 10 to 70. These levels draw on 12dicts (Alan Beale), Moby Words II (Grady Ward), Brian Kelk's UK English Wordlist and an inflection database derived from WordNet 1.6 (Princeton University). SCOWL licence, whose main notice is reproduced below. The notice embedded in the game omits the paragraph specific to a package that only enters at level 80, which is not used; the complete file is in the SCOWL 2020.12.07 archive.

2. Changes made by Aplomb

The word lists were modified by Aplomb: cleaned (proper nouns, acronyms, compound words), accents removed according to each language's tile alphabet, coarse or offensive words removed, words sorted and added, then compiled into a format specific to the game.
