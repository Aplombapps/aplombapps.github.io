Un seul paiement, aucun abonnement, aucune publicité, aucun autre achat dans le jeu. Assurez-vous d'avoir le droit d'utiliser la grille que vous importez (par exemple pour votre usage personnel).

Le code contient la grille, et selon le cas votre partie (coups et temps) ou vos règles, ainsi que le prénom facultatif que vous y inscrivez (24 caractères au plus). Aucun code ne passe par un serveur de l'éditeur ; l'éditeur ne les reçoit, ne les conserve ni ne les modère.

Vous êtes l'auteur de ce que vous partagez et vous en répondez : n'inscrivez dans un code ni le nom d'un tiers sans son accord, ni un propos injurieux, diffamatoire ou contraire à la loi, et ne partagez pas comme vôtre une grille dont vous n'avez pas les droits. Le jeu vérifie un code reçu avant de l'ouvrir (code complet, grille valable, solution unique, partie qui mène à la solution) ; cette vérification est technique et ne porte pas sur le prénom inscrit. N'ouvrez que les codes de personnes que vous connaissez.
